# Kingdoms of Iron – MVP Prototype

Dieses Verzeichnis enthält einen lauffähigen Browsergame-Prototypen mit:

- Ressourcenproduktion pro Zeit-Tick
- Gebäudeausbau mit Bau-Warteschlange
- Einheitentraining mit Warteschlange
- Markt/Handel
- Quest-System
- einfacher PvP-Angriffssimulator mit Beute/Verlusten
- Persistenz per `localStorage`

## Lokal starten

```bash
cd public
npm install
npm run start
```

Danach im Browser öffnen (standardmäßig z. B. `http://localhost:3000`).
